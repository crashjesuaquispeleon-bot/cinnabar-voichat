# Cinnabar Voice Chat — Alpha installers

This branch produces two installable Alpha packages from GitHub Actions. They are test artifacts, not a stable release.

## Download the builds

Open the [Voice Chat Alpha Builds workflow](https://github.com/crashjesuaquispeleon-bot/cinnabar-voichat/actions/workflows/voice-chat-alpha.yml), select the latest successful run for `feature/voice-chat-foundation`, and download its artifacts:

- `cinnabar-voice-alpha-windows-x64`: Windows x64 setup `.exe` and MSI.
- `cinnabar-voice-alpha-android-arm64`: Android `arm64-v8a` APK.

Artifacts are retained by GitHub Actions for 14 days. A failed or still-running job does not have a downloadable package.

## Windows

Run `Cinnabar-0.1.31-x64-setup.exe` and follow the installer. The Alpha package is unsigned when no Windows signing certificate is configured, so Windows SmartScreen may display an unknown-publisher warning. This is a development build, not a signed public release.

## Android

The APK targets `arm64-v8a` devices. Install it manually from the downloaded APK and approve Android's install-from-this-source prompt when asked. The build uses a temporary test-signing key generated by CI. Because that key changes between builds, uninstall the previous Alpha APK before installing a newer one; uninstalling may remove local application data.

The microphone is optional. The manifest declares `RECORD_AUDIO` but does not require microphone hardware for installing Cinnabar. The app asks for microphone permission; declining it leaves ordinary gameplay available and offers a direct route to Android's app-permission settings. After granting access in Android settings, use the microphone permission retry control in Sound settings. The Sound settings default to Open Microphone for touch-only devices. Selecting Push to Talk uses the **V** key on a keyboard; an on-screen Android PTT button is not yet implemented.

## What this Alpha does and does not prove

The Windows installer and Android APK package the Cinnabar game client and the voice-chat client code. They include the local microphone policy, device selection, mute/sensitivity settings, per-speaker playback mixer and the separate voice IPC client.

**Real online room voice still requires an operator deployment.** The FriendHost-scoped admission broker is implemented separately in [cinnabar-api PR #1](https://github.com/crashjesuaquispeleon-bot/cinnabar-api/pull/1), but its Worker and the public WSS SFU are not deployed. The launcher forwards the public endpoint and ICE JSON to the Go core; Alpha builds obtain these at compile time from the repository Actions variables `CINNABAR_VOICE_WSS_ENDPOINT` and `CINNABAR_VOICE_ICE_SERVERS`. These variables may contain only a WSS URL and public STUN configuration. Never put broker keys, SFU control tokens or TURN credentials in a build variable or APK. Missing/invalid ICE keeps the voice bridge disabled. A successful installer build is not proof that two players can already talk.

The current media transport is provisional PCM over WebRTC DataChannels. Opus/RTP, adaptive jitter buffering, the in-game participant panel and physical microphone qualification across Windows and Android remain future Alpha milestones. Keep the pull request Draft until the trust chain, real two-client tests, packaging checks and device tests pass.

The workspace version remains `0.1.31`; these CI artifacts do not create or replace the `0.1.31` release.
